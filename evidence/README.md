# CAUSALGUARD-EDGE — Experimental Evidence

This directory contains evidence from the dataset preparation and object detection/tracking experiments.

## 1. Dataset and video splits

The video dataset contains 112 videos, divided by source video:

| Split | Videos |
|---|---:|
| Training | 78 |
| Validation | 16 |
| Testing | 18 |
| **Total** | **112** |

The split is performed at video level to keep videos separate across the three subsets.

## 2. Detection and tracking configuration

| Component | Configuration |
|---|---|
| Object detector | YOLO26n |
| Object tracker | ByteTrack |
| Image size | 640 |
| Confidence threshold | 0.25 |
| Processing device | CUDA GPU |
| Object classes | Person, Car, Motorcycle, Bus, Truck |

## 3. Tracking results

| Split | Videos processed | Detection records |
|---|---:|---:|
| Training | 78 | 238,088 |
| Validation | 16 | 44,120 |
| Testing | 18 | 38,569 |
| **Total** | **112** | **320,777** |

Detection records represent rows produced by the detection and tracking pipeline. They are not counts of unique objects, verified detections, or ground-truth near-miss events.

## 4. Evidence directory structure

- `01_dataset_and_splits/` — Dataset split summaries and distribution charts.
- `02_training/` — Training tracking visual evidence.
- `03_validation/` — Validation tracking visual evidence and audit material.
- `04_testing/` — Held-out testing tracking visual evidence.
- `05_algorithm_comparison/` — Reserved for algorithm comparison results.
- `06_near_miss_and_causal_analysis/` — Reserved for near-miss and causal analysis evidence.
- `07_system_and_dashboard/` — Reserved for system and dashboard evidence.
- `08_reports_and_metrics/` — Tracking summaries and reports.

## 5. Interpretation and limitations

The contact sheets provide qualitative examples of object detection and tracking outputs on selected video frames.

Overlapping bounding boxes and labels may occur in crowded scenes. These visual examples do not independently establish detection precision, recall, tracking accuracy, or near-miss detection performance.

The tracking records are not ground-truth labels. Candidate near-miss events generated by downstream heuristics must not be interpreted as verified incidents without independent validation.

Training, validation and testing are kept as separate video-level subsets. Testing results should be used as held-out evaluation evidence.

## 6. Reproducibility

The original video files and model weights are not included in this evidence directory. The CSV summaries and visual examples document the outputs generated during the experiments.
